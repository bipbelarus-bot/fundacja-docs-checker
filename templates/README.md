# Templates

Эта папка предназначена для универсальных шаблонов документов Fundacji.

Рекомендуется хранить здесь только нейтральные шаблоны без персональных данных и без утверждения неподтверждённых фактов.

Перед использованием шаблона всегда проверяйте актуальный Statut, KRS, компетенции органов, quorum, większość głosów и актуальные формы KRS.
